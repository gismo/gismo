# gismo Runtime Module System

This directory contains the infrastructure for gismo's runtime plugin/module system.
Optional modules (e.g. `gsOptim`, `gsHLBFGS`) can be built as separate shared
libraries (CMake `MODULE`) and loaded at runtime by `gsModuleLoader`, instead of
being compiled into `libgismo.so`.

---

## Files in this directory

| File | Purpose |
|------|---------|
| `gsModuleInfo.h` | POD struct (`gismo_module_info_t`) exchanged during the version handshake |
| `gsModuleLoader.h` / `.cpp` | Host-side loader: `dlopen`, version check, registration trigger |
| `gsModuleVersion.h.in` | CMake template; each module generates its own version header from this |
| `README.md` | This file |

These headers are installed to `<prefix>/include/gismo/gsModules/` and are part of
the public gismo API available to external module authors.

---

## Architecture overview

```
libgismo.so                              gsOptim_module.so
  gsModuleLoader ──── dlopen ─────────►  gismo_module_info()
  gsOptimizerRegistry ◄── register_ ──   gismo_module_register()
  (singleton lives here, GISMO_EXPORT)   (links libgismo.so, RTLD_LOCAL)
```

A MODULE `.so` is loaded with `RTLD_LOCAL` so its internal symbols do not pollute
the global symbol table.  However, calls to `GISMO_EXPORT` symbols in `libgismo.so`
(such as `gsOptimizerRegistry::getMutableInstance()`) resolve to the single
authoritative copy in the host library, ensuring one shared registry.

## Using modules (user side)

Call `gsModuleLoader::loadAll()` **once** at program start, before any registry
query.  It scans the module directory and loads all valid MODULE `.so` files.

```cpp
#include <gsModules/gsModuleLoader.h>
#include <gsOptimizer/gsOptimizerRegistry.h>

int main() {
    // Load all installed MODULE .so files:
    gismo::gsModuleLoader::loadAll();

    // Or load a specific module:
    // gismo::gsModuleLoader::load("/path/to/gsOptim_module.so");

    if (gismo::gsOptimizerRegistry::has("gsOptim-BFGS"))
        auto opt = gismo::gsOptimizerRegistry::get("gsOptim-BFGS");
}
```

### Module search path (loadAll)
1. `GISMO_MODULE_DIR` environment variable (if set).
2. Compile-time install prefix: `GISMO_MODULE_INSTALL_DIR` (baked into
   `gsConfig.h` from `gsConfig.h.in`).

Set `GISMO_MODULE_DIR` during development to point at your build tree's
`lib/gismo/modules/` directory.

## Version handshake

Every MODULE `.so` must export `gismo_module_info()` returning a pointer to a
`gismo_module_info_t` struct filled at compile time.  The loader checks:

| Field | Check | Failure |
|-------|-------|---------|
| `abi_major` | Must equal host `GISMO_MAJOR` | Hard reject + `dlclose` |
| `abi_minor` | Must be ≤ host `GISMO_MINOR` | Hard reject + `dlclose` |
| `coeff_type` | Must equal `GISMO_COEFF_TYPE_STR` (e.g. `"double"`) | Hard reject + `dlclose` |

Patch level is not checked — patch-level changes are always ABI-compatible by policy.

## Writing a new module

Follow these steps using `optional/gsOptim/` as a reference implementation.

### 1. Create the module directory

```
optional/gsMyModule/
├── CMakeLists.txt
├── gsMyModule.h         # class definitions + static registrar
├── gsMyModuleEntry.cpp  # C-linkage entry points (MODULE .so only)
├── gsMyModuleInit.cpp   # legacy: just #include <gsMyModule/gsMyModule.h>
└── vcpkg.json           # optional: vcpkg manifest for the module
```

### 2. `gsMyModule.h` — classes and registrar

Define your classes and add the static registrar in an anonymous namespace.
The registrar fires both in header-only mode (when the user includes the header)
and in MODULE mode (when the `.so` is `dlopen`-ed via `.init_array`).

```cpp
// gsMyModule.h
#pragma once
#include <gsCore/gsLinearAlgebra.h>
#include <gsMyRegistry/gsMyRegistry.h>  // the registry this module populates

namespace { // anonymous — one registrar per TU
    struct gsMyModuleRegistrar {
        gsMyModuleRegistrar() {
            gismo::gsMyRegistry::register_("MyAlgo", []() {
                return gismo::gsMyBase<real_t>::uPtr(new gsMyAlgo<real_t>());
            });
        }
    };
    static gsMyModuleRegistrar gsMyModule_registrar_;
}
```

### 3. `gsMyModuleEntry.cpp` — C-linkage entry points

This file is compiled **only** into the MODULE `.so` (`GISMO_BUILD_MODULE_LIB=ON`).

```cpp
#include <gsCore/gsExport.h>
#include <gsModules/gsModuleInfo.h>
#include <gsMyModule/gsMyModule.h>
#include "gsMyModuleModuleVersion.h"   // generated by CMake

using namespace gismo;

static const gismo_module_info_t s_info = {
    GISMO_MODULE_ABI_VERSION_MAJOR,
    GISMO_MODULE_ABI_VERSION_MINOR,
    GISMO_MODULE_NAME,       // "gsMyModule"
    GISMO_MODULE_VERSION,    // e.g. "1.0.0"
    GISMO_MODULE_COEFF_TYPE,
    GISMO_MODULE_INDEX_TYPE,
    {}                       // reserved — zero-initialized
};

extern "C" GISMO_EXPORT const gismo_module_info_t* gismo_module_info() {
    return &s_info;
}

extern "C" GISMO_EXPORT void gismo_module_register() {
    // Repeat registrations here (belt-and-suspenders; calls are idempotent).
    gsMyRegistry::register_("MyAlgo", []() {
        return gsMyBase<real_t>::uPtr(new gsMyAlgo<real_t>());
    });
}
```

### 4. `CMakeLists.txt` — two build paths

```cmake
project(gsMyModule)
include(gsConfig)

# ... fetch external dependencies here if needed ...

include_directories(${GISMO_INCLUDE_DIRS})

# ---------------------------------------------------------------
# MODULE build path (runtime-loadable .so)
# ---------------------------------------------------------------
if(GISMO_BUILD_LIB AND GISMO_BUILD_MODULE_LIB)

  include(gsModule)
  gismo_add_module(gsMyModule "1.0.0"
    ${CMAKE_CURRENT_SOURCE_DIR}/gsMyModuleEntry.cpp)

  install(DIRECTORY ${PROJECT_SOURCE_DIR}
    DESTINATION include/gismo
    FILES_MATCHING PATTERN "gsMyModule/*.h")

# ---------------------------------------------------------------
# Legacy path: compiled into libgismo.so, or header-only
# ---------------------------------------------------------------
else()

  set(gismo_EXTENSIONS ${gismo_EXTENSIONS}
      ${CMAKE_CURRENT_SOURCE_DIR}/gsMyModuleInit.cpp
    CACHE INTERNAL "Gismo extensions to be included")

  install(DIRECTORY ${PROJECT_SOURCE_DIR}
    DESTINATION include/gismo
    FILES_MATCHING PATTERN "gsMyModule/*.h")

endif()

# Examples (both paths)
aux_cpp_directory(${CMAKE_CURRENT_SOURCE_DIR}/examples FILES)
foreach(file ${FILES})
  add_gismo_executable(${file})
endforeach()
```

### 5. Register in `submodules.txt`

Add your module name to the list so it is included by default (or document
how to enable it via `-DGISMO_OPTIONAL=gsMyModule`):

```cmake
set(SUBMODULES_TXT "gsOptim;gsHLBFGS;gsMyModule")
```

### 6. Add a `vcpkg.json` (optional)

```json
{
  "name": "gismo-gsmymodule",
  "version": "1.0.0",
  "description": "gsMyModule: description",
  "dependencies": [{ "name": "gismo", "version>=": "25.07.0" }]
}
```

## Registry singleton requirement

Every registry that modules populate (e.g. `gsOptimizerRegistry`) **must** have
its `getMutableInstance()` defined in a `.cpp` file compiled into `libgismo.so`,
not inline in the header.  If the singleton is inline, each loaded `.so` gets its
own private copy and registrations are invisible to the host.

Correct pattern:

```cpp
// gsMyRegistry.h  — declaration only
class gsMyRegistry {
    ...
    static GISMO_EXPORT RegistryData& getMutableInstance();
};

// gsMyRegistry.cpp  — one definition, compiled into libgismo.so
gsMyRegistry::RegistryData& gsMyRegistry::getMutableInstance() {
    static RegistryData* instance = new RegistryData();
    return *instance;
}
```
